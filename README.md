# Alstate

**Alstate is a customizable learning-state engine for building adaptive learning applications.**

Alstate helps applications decide:

* what a learner should study next;
* when an item should be reviewed;
* how learner feedback changes its learning state.

Applications provide learning items and learner feedback. Alstate manages learning states and produces learning and scheduling decisions.

## Why Alstate?

Many learning applications share the same underlying workflow:

1. Track a learner's state for each learning item.
2. Decide what should be learned or reviewed next.
3. Update learning states from learner feedback.
4. Schedule future learning or review.

Alstate extracts this workflow into a reusable engine, allowing applications to focus on their content, interface, and user experience.

It can be used to build applications such as:

* vocabulary trainers;
* flashcard systems;
* other adaptive learning applications.


> Alstate is currently in the early design stage. APIs and data models are not yet stable.
